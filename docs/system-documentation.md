# 0x90.deck System Documentation
## Overview\n0x90.deck is a DIY Streamdeck and Macro Pad based on the ESP32-S3 microcontroller. It provides native USB-HID emulation, allowing it to function as a keyboard and media control device without additional software.
## Features\n- Native USB-HID Emulation: Works on Windows, macOS, and Linux.\n- Visual Hotkey Editor: Build complex keyboard combinations directly in the browser.\n- Integrated Icon Picker: Choose symbols for macros from a Bootstrap iconset.\n- Web-IDE & File Browser: Edit configuration files or HTML interface using an integrated Ace Editor.\n- Multi-Layer Support: Switch between different key layouts (e.g., Gaming, Video Editing).\n- Kabellose OTA Updates: Flash new firmware versions over-the-air via the web interface.
## Hardware Requirements\n- **Controller:** ESP32-S3 (USB port must be directly connected to GPIOs 19 and 20 for USB-HID).\n- **Buttons/Switches:** Any mechanical switches (e.g., Cherry MX) connected to the GPIOs with GND via INPUT_PULLUP.\n- **Case:** Ready for 3D printing (STL files available in the `/hardware` directory).
## Software Setup & Installation\n1. Clone the repository:\n   ```bash\ngit clone [https://github.com/DEIN_GITHUB_NAME/0x90.deck.git](https://github.com/DEIN_GITHUB_NAME/0x90.deck.git)\ncd 0x90.deck\n```\n2. Prepare the LittleFS filesystem:\n   - Open the project in PlatformIO.\n   - Navigate to PlatformIO menu (Ant icon).\n   - Select your board and click on Upload Filesystem Image under Platform.\n3. Flash the firmware:\n   - Click on Upload and Monitor to compile and upload the code to the board.
## Usage\nAfter the first start, 0x90.deck sets up its own WLAN: ESP32-MacroPad-Setup.\nConnect to this network and open [http://192.168.4.1](http://192.168.4.1) in your browser to configure your home WiFi settings.\nOnce connected to your home network, access the interfaces via:\n- [http://<esp-ip>/](http://<esp-ip>/) - Main page (Dashboard).\n- [http://<esp-ip>/editor](http://<esp-ip>/editor) - Visual Hotkey & Icon Picker.\n- [http://<esp-ip>/ide](http://<esp-ip>/ide) - Integrated Web IDE for live code changes.\n- [http://<esp-ip>/update](http://<esp-ip>/update) - Over-the-air firmware update.
