# http-api

Use this skill for HTTP clients, REST APIs, webhooks, and JSON endpoints.

Rules:
- Keep request/response shapes explicit.
- Use correct status codes, timeouts, retries, and error handling.
- Prefer standard JSON libraries and existing HTTP clients.
- Do not invent custom protocols if HTTP/JSON is enough.
- Validate inputs and sanitize outputs.
- Keep auth, headers, and query parameters simple and documented.
